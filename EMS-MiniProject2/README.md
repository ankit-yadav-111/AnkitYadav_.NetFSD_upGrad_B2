## Prerequisites
- .NET 8 SDK
- SQL Server 2022
- Visual Studio 2022
- VS Code + Live Server

## Steps to Run

### Backend
1. Open EMS-MiniProject2 solution in Visual Studio 2022
2. Open Package Manager Console
3. Set Default project to EMS.API
4. Run: Update-Database
5. Press F5 to run the API
6. API runs at: http://localhost:7189
7. Swagger UI at: http://localhost:7189/swagger

### Frontend
1. Open frontend folder in VS Code
2. Right click index.html
3. Click Open with Live Server
4. Opens at: http://127.0.0.1:5500

### Tests
1. Open Package Manager Console
2. Run: dotnet test EMS.Tests
